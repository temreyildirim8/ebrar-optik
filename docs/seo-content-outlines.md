# SEO içerik outline’ları (sonraki sprint)

## 1. Çocuk gözlüğü seçimi
- **URL:** `/rehber/cocuk-gozlugu`
- **Hedef sorgu:** çocuk gözlüğü seçimi, Kırıkkale çocuk gözlük
- **Uzunluk:** 600–900 kelime
- **H2 yapısı:**
  1. Neden doğru çerçeve önemli?
  2. Yaşa göre ölçü ve malzeme
  3. Cam türleri (kırılmaya dayanıklı vb.)
  4. Mağazada deneme süreci (Ebrar Optik)
  5. SSS / CTA → `/#iletisim`

## 2. Lens kullanımı
- **URL:** `/rehber/lens-kullanimi`
- **Hedef sorgu:** kontakt lens kullanımı, lens hijyeni
- **Uzunluk:** 600–900 kelime
- **H2 yapısı:**
  1. Günlük / aylık lens farkı
  2. Hijyen ve saklama
  3. Ne zaman doktora / optiğe dönmeli?
  4. Ebrar Optik’te lens seçenekleri → `/lens`
  5. CTA

Yayınlandığında `src/app/sitemap.ts` route listesine eklenmeli.
